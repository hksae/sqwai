# Соглашения проекта sqwai

- Коммитить каждое малое изменение отдельно, включая промежуточное и ещё не завершённое состояние задачи, чтобы история разработки сохраняла весь ход работы.
- Не объединять независимые изменения в один крупный коммит.
- Разработку новой архитектуры начинать с пункта L: shell-aware безопасность Windows; граф пока не продолжать.
